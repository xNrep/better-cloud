# Better Cloud Data — V1

Extension for TurboWarp and PenguinMod with a Render-hosted API.

## Contents
- `extension/better-cloud-data.js`: Scratch extension.
- `server.js`: Express REST API + WebSocket rooms.
- `package.json`: Node dependencies.
- `render.yaml`: Render Blueprint for the web service and PostgreSQL database.

## Deploy to Render
1. Push these files to a GitHub repository.
2. In Render, choose **New > Blueprint** and select the repository containing `render.yaml`.
3. Review the web service and PostgreSQL database, then deploy.
4. Copy the service URL, e.g. `https://better-cloud-data-api.onrender.com`.
5. In TurboWarp/PenguinMod, load `extension/better-cloud-data.js` as an **unsandboxed** custom extension.
6. Use `connect to API [URL] project [PROJECT]`, with your actual Render URL and a stable project ID.

`JWT_SECRET` is generated by Render. `DATABASE_URL` is provided by the Render PostgreSQL database. Do not put either secret in the extension.

## Important
- This is a starter V1, not a hardened public production service. Cloud-value writes/deletes/increments are currently public; do not use them for secrets or trusted game currency.
- Public cloud variable write/delete/increment routes are intentionally available without login; anyone who knows the project ID and key can potentially modify them. Do not store secrets, trusted currency, inventory or anti-cheat-sensitive state in these variables. For public games, add project-scoped write permissions and rate limits before launch.
- Registration requires a password of at least 10 characters.
- Save slots and leaderboard submissions require login.
- Leaderboard entries currently keep each player's highest score.
- Cloud updates are fetched on demand; automatic cross-client cloud change notifications are not implemented yet. Multiplayer room events use WebSocket.
- The WebSocket URL is derived from the API URL. The client joins rooms after the REST create/join call.
- Configure `CORS_ORIGIN` to your actual trusted origins before public production use if desired. CORS is not authentication.
- Render free instances and free databases may have availability, storage and sleep limitations. Check Render's current terms before relying on them for important user data.

## API quick test
After deployment:
```sh
curl https://YOUR-SERVICE.onrender.com/v1/health
```

## Local development
Use Node.js 20+, a PostgreSQL database, and:
```sh
npm install
DATABASE_URL='postgresql://...' JWT_SECRET='replace-with-a-long-random-secret-at-least-32-chars' npm start
```
